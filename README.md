# MANY Local storefront prototype

외국인 관광객을 위한 소상공인 다국어 개별 웹페이지 프로토타입입니다.

## 포함 기능

- 영어, 일본어, 중국어 전환
- 가게 이미지, 주소, 전화번호, 영업시간, 소개
- 메뉴 카테고리별 상품명, 가격, 설명, 사진
- 와이파이, 화장실, 맛있게 먹는 법, 가게 이야기
- 섹션 순서 편집: 드래그 또는 위·아래 버튼
- 내용이 없는 예비 섹션 자동 숨김
- 모바일, 태블릿, 데스크톱 반응형 레이아웃
- 지도, 전화, 공유, 와이파이 비밀번호 복사 인터랙션

## 실행

```bash
npm install
npm run dev
```

## 프로토타입 전제

- 매장과 메뉴 정보는 샘플 데이터입니다.
- 로그인, 서버 저장, 자동 번역 API는 포함하지 않았습니다.
- 언어와 섹션 순서는 현재 브라우저에만 저장됩니다.
- 음식 사진은 프로토타입용 Unsplash 원격 이미지를 사용합니다. 운영 전 실제 매장 이미지로 교체해야 합니다.
